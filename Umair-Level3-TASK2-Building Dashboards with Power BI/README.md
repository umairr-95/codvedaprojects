            📊 Power BI Stock Market Analysis Dashboard

👤 Project
Project: Stock Market Analysis Dashboard
Tool: Microsoft Power BI
Dataset: Stock Price Analyis
Focus: Data Cleaning, Data Analysis, Visualization & Interactive Dashboard Design

📌 Project Summary
The goal of this project is to use Microsoft Power BI to create an interactive stock market analysis dashboard.To find price trends, compare stock performance, and comprehend trading volume, the goal was to import, clean, transform, analyse, and visualise historical stock market data.Through the dashboard's interactive design, users can choose certain stocks and various time periods to dynamically explore the data.

🎯 Project Goals

This project's primary goals were:

*Open Power BI and import a stock market dataset.
*Use Power Query to clean and modify the dataset.
*Verify that the data types were assigned appropriately.
*Use DAX to create computed measures.
*Create interactive KPI cards.
*Make visualisations of stock price trends.
*Examine the volume of trades over time.
*Create a dashboard that is both professional and easy to use.
*Provides interactive data exploration for users.
