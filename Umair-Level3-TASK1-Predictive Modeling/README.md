Predicting and Classifying Customer Churn
📌 Project Synopsis

This project was finished as part of Task 1: Predictive Modelling (Classification), Level 3 of the Codveda Technology Data Analytics Internship. Building machine learning categorisation models that forecast a customer's likelihood of churning is the aim of this project.

🎯 Task Objective

*Preparing the dataset for customer attrition
*Manage variables that are categorical
*Utilise feature scaling
*Create training and testing sets from the dataset.
*Develop several classification models.
*Analyse the model's performance
*Examine and contrast classification models
*Use GridSearchCV to adjust hyperparameters.
*Examine the model's final output.

📊 Dataset Information
Rows: 2,666
Columns: 20
Target Variable: Churn
Target Classes: True and False
