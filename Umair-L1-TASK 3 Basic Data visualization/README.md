# Level 1 Task 3: Basic Data Visualization

This project focuses on basic data visualization using the Iris dataset. The objective was to explore dataset structure, generate meaningful charts, and interpret patterns in the data using Python libraries.

## Project Overview
The task involves:
- Loading and inspecting the dataset
- Performing simple exploratory data analysis
- Creating different types of visualizations
- Saving the generated plots
- Summarizing key observations

## Completed Tasks
1. Imported the dataset from the local file:
   - `1) iris.csv`
2. Checked dataset basics:
   - Shape
   - Column names
   - Data types
3. Created a bar chart showing the number of iris samples by species
4. Created a scatter plot comparing petal length and petal width, grouped by species
5. Created a line chart showing variation in sepal length across observations
6. Saved the charts as image files
7. Documented the major insights from each visualization

## Tools Used
- Python
- Jupyter Notebook
- Visual Studio Code

## Libraries Used
- pandas
- numpy
- matplotlib
- seaborn
- os

## Dataset
The dataset used is the classic Iris flower dataset, which contains:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width
- Species

## Visualizations Created
- Bar chart: Number of Iris by Species
- Scatter plot: Petal Length vs Petal Width
- Line chart: Sepal Length Observations

## Output Files
The following files were generated:
- `species_bar_plot.png`
- `petal_length_vs_width.png`
- `sepal_length_line_chart.png`

## Key Findings
- The bar chart helps compare the number of samples across the three species.
- The scatter plot shows the relationship between petal length and petal width and highlights differences among species.
- The line chart displays how sepal length varies across observations, making it easy to spot fluctuations.

## Notes
This project demonstrates the use of fundamental data visualization techniques to analyze a dataset and communicate results clearly through charts and plots.
