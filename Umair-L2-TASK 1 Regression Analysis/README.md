# House Price Regression Analysis

## Project Overview

This project applies a multiple linear regression model to predict house values using property and neighborhood features. The analysis uses the Boston housing dataset structure and is implemented with Python, pandas, and scikit-learn.

## Model Review

The project follows a clear and appropriate regression workflow. The train-test split ensures that model performance is evaluated on unseen data, while the coefficients provide insight into how each feature affects predicted house values.

R-squared measures the proportion of target variance explained by the model. Mean Squared Error measures the average squared difference between actual and predicted values, where lower values indicate better performance.

## Recommendations

- Compare linear regression with Ridge, Lasso, or tree-based models.
- Standardize numerical features when comparing coefficient magnitudes.
- Add visualizations for residuals and predicted versus actual values.
- Use cross-validation for more reliable performance estimates.
- Investigate outliers and influential observations.
- Confirm the dataset path before running the notebook.
