    Time Series Analysis of Stock Prices 

# Overview of the Project
This project uses Python time-series algorithms to analyse historical stock price data. The investigation focuses on Apple Inc. (AAPL), looking at price trends, seasonal patterns, residual behaviour, and moving-average smoothing.

# Goals
* Prepare and clean up previous stock price information.
* Examine the closing prices of AAPL throughout time.
* Break down the time series into:
* Values observed
* Use Matplotlib to visualise the outcomes.

# Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Statsmodels
- Jupyter Notebook

# Methodology
1. Data Loading
2. Data Cleaning
3. Exploratory Analysis
4. Time-Series Decomposition

# Restrictions
- The analysis is limited to AAPL.
- The seasonal period may not accurately reflect market seasonality because it is based on 30 observations.
- External factors that are not covered in this analysis have an impact on stock values.
- This initiative does not offer investing advice; rather, it is meant to be instructive.
